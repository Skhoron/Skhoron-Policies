# Contributing to [Skhoron-XXX]

Спасибо за интерес к проекту!

## Прежде чем начать

- Проверьте открытые issues и pull requests, чтобы не дублировать работу.
- Для крупных изменений сначала откройте issue и обсудите подход.
- Не публикуйте секреты, токены, пароли, приватные ключи или персональные данные.
- Для уязвимостей безопасности используйте `SECURITY.md`, а не публичный issue.

## Процесс

1. Форкните репозиторий.
2. Создайте отдельную ветку, например `feature/short-description`.
3. Следуйте стилю проекта.
4. Добавьте или обновите тесты, если изменение затрагивает поведение.
5. Запустите локальные проверки проекта.
6. Подпишите каждый коммит через DCO:

```bash
git commit -s -m "Add: описание"
```

7. Откройте Pull Request и объясните, что изменено и зачем.

## DCO

Проект использует Developer Certificate of Origin (DCO), если это указано в репозитории. Каждый принимаемый коммит должен содержать корректный `Signed-off-by`.

DCO не заменяет лицензию проекта. Используйте лицензию, указанную в `LICENSE` конкретного репозитория.

## Проверки

Для Rust-проектов обычно:

```bash
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-features
```

Если проект использует другие команды CI, следуйте его `README` и workflow.

## Стиль

- Rust: `cargo fmt` и `cargo clippy`.
- Commit messages и комментарии рекомендуется писать на английском для доступности международному сообществу, если проект не установил другое правило.

Участвуя в проекте, вы соглашаетесь соблюдать Code of Conduct Skhoron.
